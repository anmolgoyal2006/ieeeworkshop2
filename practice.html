Practice Problems 🏋️

10 beginner problems to try this week. Try each one yourself before looking at hints.

01
Hello World
Easy cout

Print the text "Hello, World!" to the screen. The classic first program every developer writes.

Input
None
Output
Hello, World!
Use cout << "Hello, World!"; inside your main() function.
02
Add Two Numbers
Easy cin variables

Read two integers from input and print their sum.

Input
5 7
Output
12
Declare two int variables. Read them with cin >> a >> b; then print a + b.
03
Larger of Two Numbers
Easy if/else

Read two integers. Print the larger one. If they are equal, print either.

Input
15 9
Output
15
Read a and b. Use if (a > b) to check which is larger. Don't forget the else branch.
04
Even or Odd
Easy if/else %

Read a number. Print "Even" if it is divisible by 2, otherwise print "Odd".

Input
7
Output
Odd
n % 2 gives the remainder when divided by 2. If remainder is 0 → Even. Otherwise → Odd.
05
Positive, Negative, or Zero
Easy if/else if

Read a number. Print "Positive" if > 0, "Negative" if < 0, or "Zero" if equal to 0.

Input
-5
Output
Negative
Use an if / else if / else chain. Three conditions: n > 0, n < 0, and the else covers n == 0.
06
Simple Calculator
Medium if/else operators

Read two numbers and an operator (+, -, *, /). Perform and print the result.

Input
10 + 5
Output
15
Read the operator as a char. Use if/else to check which operator was entered and perform the right operation.
07
Multiplication Table
Easy loops

Read a number n. Print its multiplication table from 1 to 10.

Input
5
Output
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
Use a for loop from i=1 to i=10. Inside the loop: cout << n << " x " << i << " = " << n*i;
08
Sum 1 to N
Easy loops variables

Read a number N. Print the sum of all integers from 1 to N.

Input
5
Output
15
Start with int sum = 0;. Use a loop from 1 to N. Inside the loop: sum = sum + i;. Print sum after the loop.
09
Marks Calculator
Medium if/else if variables

Read marks (0–100). Print the grade: A (≥80), B (≥60), C (≥40), or FAIL (<40).

Input
72
Output
B
Use an if / else if / else if / else chain. Check conditions from highest (>=80) downward. Order matters here!
10
Number Guessing Game
Medium if/else while

Pick a secret number (hardcode it). Keep asking the user to guess until they get it right. Tell them if their guess is too high or too low.

Example Run
Guess: 50 → Too high
Guess: 25 → Too low
Guess: 37 → Correct! 🎉
Concepts Used
while loop + if/else + cin in loop
Set int secret = 42; Use a while loop that keeps going until guess == secret. Inside, check if too high, too low, or correct.
