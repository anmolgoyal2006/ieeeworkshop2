Hello, World!
Easy cout

Print the exact text "Hello, World!" to the console. The legendary first step for every developer.

Input
None
Output
Hello, World!
Use cout << "Hello, World!"; inside your main() function.
02
Sum of Two Numbers
Easy cin int

Read two integers a and b from the user and print their total sum.

Input
15 25
Output
40
Declare int a, b;, read them with cin >> a >> b;, then output cout << (a + b);.
03
Positive, Negative or Zero
Easy if-else

Take an integer n as input. Print "Positive" if n > 0, "Negative" if n < 0, or "Zero" if n is 0.

Input
-9
Output
Negative
Use an if (n > 0) ... else if (n < 0) ... else ... ladder.
04
Even or Odd Checker
Easy if-else modulo %

Given an integer n, check if it's even or odd using the modulo (remainder) operator.

Input
14
Output
Even
If n % 2 == 0, the number divides cleanly by 2 with no remainder → Even!
05
Larger of Two Numbers
Easy if-else

Given two numbers a and b, output the larger value. If both are equal, print either.

Input
42 99
Output
99
if (a > b) cout << a; else cout << b;
06
Multiplication Table of N
Medium for loop

Read an integer n and print its multiplication table from 1 to 10 (each product on a new line).

Input
5
Output
5 10 15 20 ... 50
Run a loop: for(int i = 1; i <= 10; i++) { cout << n * i << " "; }
07
Sum of First N Numbers
Medium for loop accumulator

Given n, calculate and print the sum of all whole numbers from 1 up to n (i.e. 1 + 2 + 3 + ... + n).

Input
5
Output
15 (1+2+3+4+5)
Initialize int sum = 0; before loop, then sum += i; inside the loop.
08
Count Down from N to 1
Easy while loop

Given an integer n, print all numbers counting down from n down to 1 separated by spaces.

Input
4
Output
4 3 2 1
Use while (n > 0) { cout << n << " "; n--; }.
09
College Grade Calculator
Medium else-if

Input a student's marks (0–100). Print: "A" (≥90), "B" (≥75), "C" (≥50), "D" (≥40), or "FAIL" (<40).

Input
82
Output
B
Check from top down: if (m >= 90) ... else if (m >= 75) ...
10
FizzBuzz Starter
Medium modulo % logical &&

Given n, print "FizzBuzz" if divisible by BOTH 3 and 5, "Fizz" if only divisible by 3, "Buzz" if only divisible by 5, else print n.

Input
15
Output
FizzBuzz
Crucial: Check the (n % 3 == 0 && n % 5 == 0) condition FIRST!
