🏗️ Basic Program Structure
#include <iostream>
using namespace std;

int main() {

    // your code here

    return 0;
}
Every C++ program starts with main(). Don't forget the return 0 at the end.
📥 Input & Output
// Print to screen
cout << "Hello World!";
cout << "Value: " << x;
cout << endl;  // new line

// Read input
int n;
cin >> n;

int a, b;
cin >> a >> b;

🔀 if / else
if (condition) {
    // runs if condition is TRUE
} else {
    // runs if condition is FALSE
}

// Example
if (marks >= 40) {
    cout << "PASS";
} else {
    cout << "FAIL";
}

// else if chain
if (marks >= 80)      cout << "A";
else if (marks >= 60) cout << "B";
else if (marks >= 40) cout << "C";
else                   cout << "FAIL";
🔁 for Loop
// Structure
for(int i = start; i <= end; i++) {
    // code repeats
}

// Print 1 to 5
for(int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// Output: 1 2 3 4 5

// Sum 1 to N
int sum = 0;
for(int i = 1; i <= n; i++) {
    sum = sum + i;
}
cout << sum;
i++ means i = i + 1. The loop runs while the condition is TRUE.
🔄 while Loop
// Structure
while (condition) {
    // keeps running while TRUE
}

// Count down from 5
int i = 5;
while (i > 0) {
    cout << i << " ";
    i--;
}
// Output: 5 4 3 2 1
⚙️ Functions (Basics)
// Define a function
int add(int a, int b) {
    return a + b;
}

// Call it in main
int main() {
    int result = add(3, 5);
    cout << result; // 8
    return 0;
}

// void = no return value
void greet() {
    cout << "Hello!";
}
Functions let you reuse code. Write once, use many times.
💡 Common Patterns
// Even or Odd
if (n % 2 == 0)
    cout << "Even";
else
    cout << "Odd";

// Max of two numbers
if (a > b) cout << a;
else       cout << b;

// Multiplication table of n
for(int i = 1; i <= 10; i++) {
    cout << n * i << "\n";
}

// Positive / Negative / Zero
if      (n > 0) cout << "Positive";
else if (n < 0) cout << "Negative";
else            cout << "Zero";
🐛 Error Types
TypeWhat it means
Syntax ErrorViolates language rules. Missing ; or } . Caught at compile time.
Runtime ErrorCompiles but crashes while running. e.g. divide by zero.
Logical ErrorRuns but gives wrong output. e.g. used = instead of ==.
⚠️ Most common mistake: if (x = 5) assigns, doesn't compare. Use if (x == 5).
