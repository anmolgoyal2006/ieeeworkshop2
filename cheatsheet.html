🏗️ Basic Program Structure 
#include <iostream>
using namespace std;

int main() {

    // your code logic here

    return 0;
}
Every C++ program starts at main(). return 0; indicates successful execution.

// Print text and variables

// Multiple inputs
int a, b;
cin >> a >> b;

🔀 Decision Making (if / else) 
if (marks >= 40) {
    cout << "PASS";
} else {
    cout << "FAIL";
}

// Multiple branches
if (marks >= 90)      cout << "A+";
else if (marks >= 75) cout << "A";
else if (marks >= 40) cout << "PASS";
else                   cout << "FAIL";
🔁 Loops (for & while) 
// for loop (start; condition; update)
for(int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// Output: 1 2 3 4 5

// while loop (while true)
int count = 3;
while (count > 0) {
    cout << count << " ";
    count--;
}
i++ increases by 1. i-- decreases by 1.
💡 Common Logic Patterns 
// 1. Even or Odd
if (n % 2 == 0) cout << "Even";
else            cout << "Odd";

// 2. Max of two numbers
if (a > b) cout << a;
else       cout << b;

// 3. Sum 1 to N
int sum = 0;
for(int i = 1; i <= n; i++) sum += i;
🐛 Error Diagnostics
Error TypeCause
Syntax ErrorMissing ; or typos. Compiler catches immediately.
Runtime ErrorDivide by zero or invalid RAM index. Crashes while running.
Logical ErrorCode runs fine but math/logic is wrong (e.g. = vs ==).
⚠️ Tip: Always read the line number in the compiler error message!
