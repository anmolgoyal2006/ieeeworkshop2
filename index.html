    SLIDE 14

    💀 Debugging — When Code Breaks

    Every single developer breaks code daily. Debugging is half the craft.

    🐛 Spot the Bug in this snippet:

    int marks = 50; if (marks = 40) cout << "Pass";
    Fix: marks = 40 → marks == 40
    = assigns a value  |  == checks equality

    3 Types of Errors

    SYNTAX ERROR

    Violates C++ syntax rules (e.g. missing semicolon ;). Caught at compile time.

    RUNTIME ERROR

    Compiles fine but crashes during execution (e.g. divide by 0, infinite memory loop).

    LOGICAL ERROR

    Runs smoothly but outputs wrong math/answer. Hardest to detect!

    😤
    "The Missing Semicolon"
    One tiny ; on line 42 crashed the entire project. Rite of passage.
